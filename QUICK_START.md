# AutoQA - Quick Start (60 Seconds)

Get AutoQA running in less than a minute!

---

## ✅ Requirements

- Windows 10/11
- Node.js installed (from nodejs.org)
- Ollama running (from ollama.ai)
- Model downloaded: `ollama run gemma4:e4b`

---

## 🚀 Start AutoQA

### Terminal 1: Ollama
```
ollama serve
```
Leave this running.

### Terminal 2: AutoQA

Navigate to AutoQA folder:
```
cd C:\path\to\AutoQA
```

Install dependencies (first time only):
```
npm install
```

Start server:
```
npm start
```

### Browser

Open: `http://localhost:3000`

---

## 📝 Use It

1. **Upload** - Drag-drop your Postman collection JSON
2. **Run** - Click "Run Tests"
3. **View** - Click "View Detailed Report"

---

## 🎉 Done!

That's it! AutoQA will:
- Generate test cases with AI
- Execute all tests
- Create beautiful HTML report
