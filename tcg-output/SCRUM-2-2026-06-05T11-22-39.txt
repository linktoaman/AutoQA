Test Case 1 (SCRUM-2_POS_001)
Title: Verify successful retrieval of all products using GET request
Type: functional

Preconditions:
Valid API endpoint is accessible. Authentication token (if required) is available.

Steps:
1. Send a GET request to https://qa.abcorp.com/v1/getAllProducts

Expected Result:
The API should return a status code of 200 OK, and the response body should contain an array of product objects.
